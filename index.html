📖 Caso de Estudio

Biblioteca Digital UNTEC

Descripción del proyecto

Sistema web para gestionar libros, usuarios, préstamos y devoluciones en una biblioteca universitaria.

Desafío principal

Integrar Java EE, JSP, Servlets, JDBC y MySQL utilizando el patrón MVC y resolver problemas de configuración en Eclipse y Apache Tomcat.

Solución implementada

Se desarrolló una arquitectura MVC con clases DAO, conexión mediante JDBC y operaciones CRUD para administrar la información almacenada en MySQL.

Resultado

El proyecto permitió gestionar correctamente la información de la biblioteca y fortaleció mis conocimientos en desarrollo Backend y bases de datos.
